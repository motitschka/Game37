# Game37

Rust + SDL3 emulator front end for Linux. Specs: `docs/requirements.md`, `docs/user-stories.md`,
`docs/milestones.md`, decisions in `docs/adr/`. Screen mockups: `design/mockups/*.svg`, generated by
`design/generate_mockups.py` (its constants and layout functions are the visual spec).

## Checks

- Tests: `cargo test`
- Lint: `cargo clippy --all-targets -- -D warnings`
- Format: `cargo fmt --check` (max_width 110, see `rustfmt.toml`)

All three must pass before a commit.

## Conventions

- Use the glossary in `CONTEXT.md` in code, comments and UI text: System, Game, Games Root, Display
  Title, Shelf, Carousel, Console Page, Config. Avoid the listed alternatives (ROM, platform, console).
- Systems come only from `systems::SYSTEMS`, which is in System Order. Never list Systems anywhere else.
- Tests never touch the real `~/Games`, `~/.config/game37` or `~/.local/share/game37`: use temp dirs.
- Never commit game files, BIOS, keys or secrets (NFR-6). Test fixtures are empty or tiny dummy files
  created by the tests themselves.
