# Standalone emulators for embedded systems are never used by Game37

Mesen, bsnes, SameBoy, mGBA, melonDS, RMG, PPSSPP, DuckStation and ares are installed on the owner's machine but Game37 never shows or launches them. There is no "open in standalone" fallback. Eden is also unused: Switch always goes to Ryubing. The owner chose a single play path per System over a fallback option, to keep the Options Menu simple. Don't "helpfully" add a fallback without revisiting this.
